# pano_restorations_monai

Panoramic model for cavity, fillings, impacted tooth and implant, trained on the
Kaggle "Dental Radiography" set (imtkaggleteam/dental-radiography, CC BY-SA 4.0),
the same data and 73-film test split as the original v1 Faster R-CNN detector,
so the two can be compared directly. Shares code with ../panoramic_monai and
../periapical_monai. Start: `./kaggle/push_kaggle.sh`.
